# 主站访问地域统计看板设计

## 目标

在不影响主站浏览体验、且不长期保存原始 IP 的前提下，统计：

- 按北京时间计算的每日访问人数（UV）与访问次数（PV）。
- 全球按国家或地区汇总 UV、PV。
- 中国大陆进一步按省级行政区汇总 UV、PV。
- 中国香港、中国澳门、中国台湾作为独立地区展示。

本期不做城市级统计、用户行为漏斗、实时在线人数、广告归因或跨设备身份合并。

## 已确认方案

采用主站同源采集、服务端识别 IP 的方案。

主站 Vue 应用在首次打开以及每次成功路由切换后，向主站 Go 后端发送一次轻量访问请求。浏览器不提交 IP，也不会持有管理台内部密钥。Go 后端从可信代理链读取客户端 IP，并维护一个 HttpOnly、SameSite=Lax 的第一方匿名访客 Cookie；随后使用现有管理台内部接口密钥，将访问事件转发到召回管理台。

这种方式兼顾了单页应用路由覆盖和服务端可信 IP 采集。统计失败不会阻断页面导航或主站正常功能。

## 数据流

1. Vue 路由首次加载或成功切换。
2. 前端异步调用 `POST /api/v1/analytics/visit`，仅提交当前 pathname。
3. Go 后端读取或生成匿名访客 Cookie，读取可信客户端 IP，生成唯一事件 ID。
4. Go 后端调用管理台 `POST /api/internal/righttoken/visits`，使用 Bearer 内部密钥认证。
5. 管理台解析 IP：
   - 优先使用本地 GeoLite2 City MMDB；
   - 回退到现有 RIR/可选 HTTP 解析链；
   - 无法识别时归为“未知”。
6. 管理台使用独立密钥对访客 Cookie 做 HMAC-SHA256，不保存 Cookie 原值或原始 IP。
7. 管理台保存最小访问事实，供后台按天、国家和中国省份聚合。

## 数据模型

新增 `SiteVisit`：

- `eventId`：主站生成的唯一事件 ID，用于幂等去重。
- `occurredAt`：访问发生时间。
- `visitDate`：按 `Asia/Shanghai` 计算的自然日。
- `visitorHash`：匿名访客 Cookie 的 HMAC-SHA256。
- `countryCode`：ISO 两位国家码；未知使用 `ZZ`。
- `region`：仅中国大陆保留规范化省级名称，其他国家为空。
- `path`：只保存不含 query、fragment 的 pathname，限制长度。
- `createdAt`：管理台接收时间。

索引覆盖日期、访客哈希、国家和省份查询。`eventId` 唯一，主站或网络重试不会重复增加 PV。

访问事实默认保留 180 天；本期通过管理台已有后台任务入口增加清理，超过保留期的数据不参与查询并被批量删除。

## 地域口径

- 全球列表按 ISO 国家码聚合，展示中文名称。
- `CN` 进入“中国大陆”并显示省级明细。
- `HK`、`MO`、`TW` 分别显示为“中国香港”“中国澳门”“中国台湾”，不进入大陆省份明细。
- 省份名称去除“省”“市”“自治区”“壮族自治区”“回族自治区”“维吾尔自治区”“特别行政区”等后缀，统一为稳定的短名称。
- GeoIP 解析失败、内网 IP 或测试保留 IP 统一记为“未知”。
- UV 是所选日期范围内 `visitorHash` 去重人数；每日 UV 是当日去重。国家/省份 UV 在各自地域内去重，一个访客在周期内跨地域访问时可分别计入对应地域，但总 UV 仍只计算一次。
- PV 是成功接收且通过幂等校验的访问事件数。

## 后台看板

新增管理员可见的“访问看板”页面，默认展示最近 30 天，可切换 7、30、90 天：

- 顶部指标：今日 UV、今日 PV、所选周期 UV、所选周期 PV。
- 每日趋势：按时间从旧到新展示 UV/PV，便于观察变化。
- 国家或地区排行：UV、PV、占比，默认按 PV 从高到低。
- 中国大陆省份排行：UV、PV、占比，默认按 PV 从高到低。
- 空数据、未知地域和 GeoIP 未配置都有明确提示。

看板只允许 `PRIMARY_ADMIN` 和 `ADMIN` 访问；运营人员不显示入口，直接访问也会被拒绝。

## 接口与容错

### 主站公开采集接口

`POST /api/v1/analytics/visit`

- 同源调用，不需要用户登录。
- 请求体只接受 pathname。
- 后端设置或刷新匿名访客 Cookie。
- 无论管理台暂时不可用与否，都返回无敏感信息的成功响应，避免影响主站。
- 对 pathname、请求体大小和请求频率做限制。

### 管理台内部接收接口

`POST /api/internal/righttoken/visits`

- 使用现有 current/previous 双内部密钥机制。
- 严格校验事件 ID、访客 ID、时间、IP 和 pathname。
- 对未来时间和过旧事件拒绝或归一化，避免污染统计。
- GeoIP 失败时仍保存为未知地域，不丢失 PV/UV。
- 唯一事件冲突返回幂等成功。

### 看板查询

页面服务端直接查询管理台数据库，不向浏览器暴露访问明细、访客哈希或 IP，只返回聚合结果。

## 隐私与安全

- 原始 IP 只在请求处理内存中用于 GeoIP 解析，不写数据库、日志或前端响应。
- 匿名访客 Cookie 为随机不可读值，HttpOnly、Secure（生产环境）、SameSite=Lax。
- 数据库只保留不可逆访客哈希。
- pathname 去除 query 和 fragment，避免保存令牌、邮箱或其他 URL 参数。
- 内部接口继续支持密钥轮换。
- 看板仅展示聚合数据。

## 测试与验收

- 管理台单元测试覆盖：北京时间日期、HMAC、国家/省份规范化、未知地域、幂等事件。
- 管理台查询测试覆盖：每日 UV/PV、周期总 UV/PV、国家排行、中国省份排行、跨地域访客口径。
- 管理台权限测试覆盖：管理员可见，运营人员不可见。
- Go 测试覆盖：Cookie 首次生成与复用、可信 IP、请求字段、内部密钥、上游失败不影响响应。
- Vue 测试覆盖：首次路由和后续成功路由各上报一次；上报失败不阻断导航。
- 数据库迁移、TypeScript、Go、Vue 测试全部通过。
- 浏览器验收确认：主站浏览产生统计；访问看板能切换日期范围，并正确显示全球国家和中国省份数据。
