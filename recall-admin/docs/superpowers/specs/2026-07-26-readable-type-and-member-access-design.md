# 可读字号与成员访问设计

## 目标

- 将后台现有偏小的正文、表格、表单、标签和导航字号整体提升两个视觉级别，任何业务文字不低于 12px。
- 成员必须对应已同步的 RightToken 主站注册用户。
- 成员权限由召回后台授权，但身份认证完全复用 RightToken 主站登录。
- 撤销的是召回后台访问权限，不删除主站账号、成员历史或审计记录。

## 字号

后台页面继续使用现有字体、颜色和组件，不改变信息架构。将 7–10px 的业务文字统一提升到 12px；11–17px 的文字提升 2px；24px 及以上的数据和页面标题保持现有层级，避免页面无意义膨胀。表单控件、按钮和胶囊同步提高字号，并保留当前紧凑布局。

## 添加成员

“邀请成员”改为“添加成员权限”。管理员输入主站注册邮箱和角色后，系统从已经同步到召回后台的 `UserProfile` 中查找对应用户：

- 找不到时拒绝授权，并提示该邮箱不是已同步的 RightToken 用户。
- 找到时使用 `externalUserId` 绑定主站身份，并创建或重新启用成员权限。
- 主管理员可以授权管理员或运营；管理员只能授权运营。
- 不再生成召回后台独立注册链接、密码或二次验证流程。
- 成员首次从 RightToken 主站进入时，现有 SSO 票据继续完成身份校验。

## 撤销权限

成员列表新增“撤销权限”操作：

- 主管理员不能被撤销。
- 成员不能撤销自己。
- 主管理员可以撤销管理员和运营；管理员只能撤销运营。
- 撤销后设置 `Member.active=false`，立即删除该成员全部召回后台会话。
- 该成员负责的用户解除负责人；未完成任务解除负责人并回到待分配状态。
- 保留成员、历史任务和审计记录，之后可以用同一邮箱重新授权。

## 验证

- 单元测试覆盖主站用户校验、角色边界、自撤销/主管理员保护、会话与任务释放。
- 组件测试覆盖添加成员和撤销权限交互。
- 静态测试保证后台业务字号不存在低于 12px 的值。
- 最后运行单元测试、类型检查、构建，并在本地成员页面和主要工作台目视确认。
