# 系统设置真实邮箱配置设计

## 背景

系统设置页当前将邮箱连接状态拆成固定的“Namecheap 客服邮箱”和“企业微信邮箱”两项，但判断逻辑与真实配置不一致：任意数据库邮箱都会让 Namecheap 显示为已配置，而企业微信邮箱只检查环境变量，不读取已保存的邮箱记录。这会导致已经成功保存的企业邮箱仍显示“待配置”。

本次改造让设置页以真实持久化数据为准，移除 Namecheap 专属功能，并补齐多个邮箱的新增与配置永久删除能力。

## 目标

- 邮箱状态只来源于数据库中的真实邮箱记录，不再使用固定品牌标签推断状态。
- 完全移除 Namecheap 专属入口、默认值和用户界面文案。
- 管理员可以新增多个企业微信邮箱或其他标准 SMTP/IMAP 邮箱。
- 管理员可以永久删除邮箱登录配置，同时完整保留该邮箱关联的邮件和群发历史。
- 企业微信应用与企微群机器人继续按真实凭据或现有环境配置显示状态。
- 新增、测试、同步和删除操作都有明确反馈，并继续遵守管理员权限、同源校验和审计要求。

## 非目标

- 不增加 OAuth 邮箱授权。
- 不自动识别邮箱服务商或自动发现服务器地址。
- 不提供邮箱配置编辑；同一邮箱地址再次保存时重新激活历史邮箱记录并写入新配置。
- 不改变企业微信应用、企微群机器人的配置表单或连接协议。
- 不迁移或删除服务器环境变量中的旧 Namecheap 配置；它们不再参与设置页状态展示，也不再作为新增邮箱默认值。

## 信息架构与界面

### 外部连接

“外部连接”区域保留为连接概览，但只展示可验证的真实项目：

- 客服邮箱：显示仍有有效配置的邮箱总数和启用数量；没有有效配置时显示“尚未添加邮箱”。
- 企业微信应用：沿用已保存凭据或现有环境配置的真实状态。
- 企微群机器人：沿用已保存凭据或现有环境配置的真实状态。

不再出现“Namecheap 客服邮箱”或单独的固定“企业微信邮箱”状态标签。具体邮箱状态由“已保存邮箱”列表承担，避免概览与详情重复或矛盾。

### 已保存邮箱

只要存在邮箱记录，就展示“已保存邮箱”列表。每条记录展示：

- 管理员设置的连接名称；
- 邮箱地址；
- 是否启用；
- 最近连接/同步结果；
- “测试连接”“立即收取邮件”“删除邮箱”操作。

删除操作使用危险样式。点击后使用浏览器确认对话框，明确说明邮箱账号、密码和收发服务器配置会永久删除且无法恢复，但历史邮件会话、邮件内容和群发记录会保留。用户取消时不发送请求。

### 新增邮箱

表单标题改为“新增邮箱连接”，邮箱类型只保留：

- 企业微信邮箱；
- 其他邮箱（手动设置 SMTP/IMAP）。

默认选择企业微信邮箱。连接名称默认使用“企业微信邮箱”，但服务器地址与端口不预填品牌值，避免提交错误的 Namecheap 参数。管理员填写邮箱地址、登录账号、密码、SMTP/IMAP 地址、端口和安全连接选项后保存。

保存成功后清空密码字段、显示成功反馈并刷新服务端页面数据；同一邮箱地址再次提交时更新并重新激活原记录，不创建重复项，也不影响其历史邮件。

## 数据流

### 查询

`getSettingsWorkspaceOverview` 从 `Mailbox` 表读取配置尚未删除的邮箱记录，并直接聚合邮箱总数与启用数量。邮箱概览不再检查 `SMTP_*` 或 `WECOM_MAIL_HOST` 环境变量，也不再将任意邮箱归类为 Namecheap。

企业微信应用和机器人仍读取 `IntegrationCredential` 的启用状态，并保留已有环境变量兼容逻辑。

### 新增或更新

沿用 `POST /api/integrations/mailboxes` 与 `saveMailboxCredential`：

1. 校验管理员权限和同源请求；
2. 校验企业微信邮箱或自定义邮箱类型及 SMTP/IMAP 配置；
3. 加密敏感配置；
4. 按邮箱地址新增或更新 `Mailbox`；
5. 写入现有邮箱凭据保存审计记录；
6. 返回不包含密码的邮箱摘要。

API 和持久化类型移除 `NAMECHEAP`，只接受 `WECOM_MAIL` 与 `CUSTOM`。已有加密配置中的 `NAMECHEAP` 值仍可被运行时读取，避免上线后旧邮箱立即失效；本次只禁止再通过界面或 API 新增 Namecheap 类型。

为支持保留历史，`Mailbox.encryptedConfig` 改为可空，并新增 `configurationDeletedAt`。正常邮箱的加密配置非空、删除时间为空；已删除配置的历史邮箱记录则配置为空、删除时间非空且 `enabled` 为 `false`。所有可发送、收信、测试或供用户选择的邮箱查询都必须排除已删除配置的记录。

### 永久删除

新增 `DELETE /api/integrations/mailboxes/:id`。这里的“删除”仅永久清除连接凭据，保留作为历史外键锚点的 `Mailbox` 记录。操作必须通过管理员权限与同源校验，并在单个数据库事务中完成：

1. 查询仍有有效配置的邮箱记录；
2. 将 `encryptedConfig` 设为空、`enabled` 设为 `false`，并记录 `configurationDeletedAt`；
3. 清空连接测试和同步错误状态，避免历史连接状态被误认为仍可使用；
4. 写入 `mailbox.configuration_deleted` 审计记录，记录邮箱地址域名、原启用状态以及保留的邮件会话、邮件内容和群发记录数量，不记录账号、密码或完整加密配置。

所有步骤必须原子完成。任一步失败时回滚，原配置继续保持可用。

邮件会话、邮件内容、群发任务、收件人结果、素材关联、共享素材实体和底层文件均保持不变。

如果管理员以后使用相同邮箱地址重新新增连接，保存逻辑复用原 `Mailbox` 记录，写入新的加密配置，清空 `configurationDeletedAt`，并保留原有历史关系。

## 错误处理

- 未登录返回 401，无权限返回 403。
- 非同源删除请求沿用现有 CSRF 错误处理。
- 邮箱不存在或配置已经删除时返回 404，界面提示“邮箱配置已不存在”，随后刷新列表。
- 删除事务失败返回稳定错误码，界面提示“邮箱配置删除失败，原有数据未改变”。
- 删除期间禁用该邮箱的其他操作，按钮显示“正在删除”。
- 保存校验失败继续使用面向管理员的中文提示，不暴露数据库或加密错误。

## 测试策略

### 单元与组件测试

- 邮箱表单不再出现 Namecheap 选项或 `mail.privateemail.com` 默认值。
- 表单可以提交企业微信邮箱和自定义 SMTP/IMAP 邮箱。
- 删除按钮先确认仅永久删除连接配置并保留历史；取消时不请求 API，确认时发送 DELETE。
- 删除成功刷新页面并显示成功反馈；失败显示错误且恢复按钮。
- 设置页概览根据真实邮箱数量显示，不再生成 Namecheap/企业邮箱固定状态。

### 集成测试

- DELETE 接口拒绝未登录、无权限和跨站请求。
- 删除不存在的邮箱返回 404。
- 删除邮箱配置会清空加密凭据、停用邮箱并标记删除时间。
- 删除邮箱配置后，该邮箱的群发任务、邮件会话和邮件内容完整保留。
- 已删除配置的邮箱不会出现在发送、同步、测试或邮箱选择列表中。
- 用相同邮箱地址重新新增配置会复用历史邮箱记录并恢复可用状态。
- 删除事务写入脱敏审计记录。
- 事务失败时邮箱配置及关联历史保持不变。
- POST 接口拒绝 `NAMECHEAP`，接受 `WECOM_MAIL` 和 `CUSTOM`。

### 回归验证

- 现有测试连接与立即收信功能仍可使用。
- 邮件发送、回复和群发选择器不会显示已删除配置的邮箱。
- 历史邮件和群发详情仍能显示已删除配置邮箱的名称与地址。
- 企业微信应用和机器人状态不受影响。
- 桌面和移动端均能清晰展示邮箱列表、操作按钮、确认与反馈状态。

## 验收标准

1. 已保存企业微信邮箱时，设置页不再显示“企业微信邮箱待配置”，也不会误显示 Namecheap 已配置。
2. 设置页及新增接口不再提供 Namecheap 配置能力。
3. 管理员可以连续新增多个不同邮箱地址。
4. 管理员确认删除后，邮箱账号密码与服务器配置永久消失，邮箱不再可用于发送、收信或测试。
5. 邮件会话、邮件内容和群发记录在删除配置后完整保留并仍可查看。
6. 用相同地址重新新增邮箱时恢复原历史邮箱身份，不产生重复记录。
7. 删除失败不会留下部分删除状态。
8. 页面状态在新增或删除后立即与数据库一致。
9. 敏感账号密码始终加密保存，不在查询、响应、审计或页面中回显。
