# 用户中心分组快捷筛选设计

## 目标

将用户中心筛选栏中的分组下拉菜单改为始终可见的快捷胶囊，使运营人员能够直接点击 `F、A、B、C、D、E、G` 完成分组筛选，并在常见桌面宽度下保持整条筛选栏单行显示。

## 页面布局

- 筛选栏从左至右依次为：
  1. 搜索用户
  2. 分组快捷胶囊
  3. 国家
  4. 地区
  5. 负责人
  6. 应用筛选
  7. 清除
- 搜索框使用剩余空间，但设置合理的最小宽度。
- 国家、地区、负责人和操作按钮使用紧凑固定宽度。
- 分组区域固定展示 `全部、F、A、B、C、D、E、G`，不再显示下拉菜单。
- 桌面宽度下筛选栏禁止换行，确保所有控件位于同一行。

## 交互

- 每个分组胶囊都是表单提交按钮。
- 点击胶囊立即提交当前表单，因此会同时保留并应用搜索、国家、地区和负责人字段中尚未提交的内容。
- 当前分组使用主色背景、白色文字和明确的选中状态。
- 未选中的分组使用浅色背景与边框，并提供悬停、键盘焦点和按下状态。
- 点击“全部”清除分组限制，但保留其他筛选条件。
- “清除”继续返回 `/users`，清除全部筛选条件。

## 可访问性

- 分组区域使用 `fieldset` 与 `legend`，对辅助技术暴露“分组”名称。
- 当前分组按钮使用 `aria-pressed="true"`。
- 所有按钮保持至少 36 像素的可点击高度和清晰的键盘焦点样式。
- 不用颜色作为唯一选中信号；选中状态同时由 `aria-pressed` 表达。

## 响应式行为

- 大屏和常规桌面宽度：整条筛选栏单行显示。
- 较窄窗口：允许筛选栏按完整控件分组换行，不压缩文字、不裁切胶囊。
- 分组胶囊本身始终保持一字排开；空间不足时分组区域可横向滚动，不能退回下拉菜单。

## 数据与网址

- 继续使用现有 `segment` 查询参数，不修改用户查询接口。
- 分组顺序仅属于展示逻辑，后端仍接受 `A` 至 `G`。
- 分页链接继续保留当前分组和其他查询参数。

## 验收标准

- 用户中心不再出现分组下拉菜单。
- 页面始终直接显示 `全部、F、A、B、C、D、E、G`。
- 点击任一分组后网址包含对应 `segment` 参数，用户列表按该组刷新。
- 点击分组时，搜索、国家、地区和负责人条件不会丢失。
- 当前分组视觉状态和 `aria-pressed` 状态一致。
- 常规桌面视口下筛选栏为一行。
- 单元测试、类型检查、代码检查、生产构建和用户中心浏览器验证通过。
