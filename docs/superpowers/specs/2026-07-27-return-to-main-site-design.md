# 召回后台“返回主站”设计

## 目标

在召回后台顶部栏右侧、通知图标左侧增加“返回主站”入口。用户点击后在当前标签页返回 RightToken 主站控制台，不产生新的登录步骤。

## 界面

- 使用带左向返回箭头的次要按钮，标签为“返回主站”。
- 按钮放在顶部栏操作区最左侧，位于通知图标和当前成员名称之前。
- 视觉样式沿用顶部栏现有灰蓝色文字、圆角和悬停背景，不使用主品牌色填充，避免与页面主操作竞争。
- 桌面端显示图标和文字；窄屏仅显示图标，并保留完整无障碍名称和悬停提示。
- 按钮具备清晰的键盘焦点状态。

## 地址与配置

- 新增独立的服务端环境变量 `RIGHTTOKEN_DASHBOARD_URL`，用于配置主站控制台地址。
- 本地默认值：`http://127.0.0.1:3002/dashboard`。
- 生产默认值：`https://righttoken.ai/dashboard`。
- 不复用 `RIGHTTOKEN_ADMIN_URL`，避免把“返回主站”与 SSO 登录入口耦合。
- 服务端布局读取并校验地址，再将地址作为属性传给顶部栏组件；客户端组件不直接读取服务端环境变量。
- 点击使用普通链接在当前标签页跳转。

## 测试

- 环境解析测试验证显式配置、本地默认值和生产默认值。
- 顶部栏组件测试验证按钮文本、链接地址和无障碍名称。
- 生产构建、类型检查和代码检查必须通过。
- localhost 验证按钮位于指定位置，点击后返回主站控制台。

## 范围

本次只增加返回入口及其配置，不修改 SSO、角色权限、主站登录状态或其他顶部栏功能。
